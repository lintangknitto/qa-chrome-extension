# code-review-and-quality

## Apa ini
Metodologi review kode multi-aspek. Ini adalah metodologi review itu sendiri — agent seperti `reviewer` sebaiknya memanggil skill ini daripada mengarang checklist sendiri.

## Kapan dipakai
- Sebelum merge perubahan apa pun.
- Saat mereview kode buatan sendiri, agent lain, atau manusia lain.
- Saat perlu menilai kualitas kode dari berbagai dimensi sebelum masuk ke branch utama.

- `SKILL.md` — instruksi lengkap skill ini.
