# test-driven-development

## Apa ini
Skill yang mendorong pengembangan dengan pendekatan test-driven (TDD).

## Kapan dipakai
Saat mengimplementasikan logika apa pun, memperbaiki bug apa pun, atau mengubah behavior apa pun. Juga saat perlu membuktikan kode benar-benar bekerja, saat ada laporan bug masuk, atau saat akan mengubah functionality yang sudah ada.

- `SKILL.md` — instruksi lengkap skill ini.
