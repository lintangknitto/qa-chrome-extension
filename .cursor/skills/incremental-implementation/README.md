# incremental-implementation

## Apa ini
Skill yang mendorong perubahan kode dikerjakan secara bertahap/incremental, bukan sekaligus dalam satu langkah besar.

## Kapan dipakai
- Mengimplementasikan fitur atau perubahan yang menyentuh lebih dari satu file.
- Saat akan menulis banyak kode sekaligus, atau saat sebuah task terasa terlalu besar untuk diselesaikan dalam satu langkah.

## File terkait
- `SKILL.md` — instruksi lengkap skill ini.
