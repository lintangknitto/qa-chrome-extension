# debugging

## Apa ini
Metodologi debugging sistematis berbasis root-cause untuk kasus "sesuatu yang tadinya jalan (atau seharusnya jalan) jadi rusak" — reproduksi masalah secara konsisten, isolasi kasus paling kecil yang gagal, bisect ke perubahan yang menyebabkannya, lalu perbaiki akar masalahnya, bukan sekadar simptomnya.

## Kapan dipakai
Saat menyelidiki bug, error yang tidak terduga, regresi, atau kasus "ini tadinya jalan, sekarang enggak".

## Bukan untuk
Review kode umum atau menulis test baru dari nol (lihat `code-review-and-quality`, `test-driven-development`).
