# project-bootstrap

## Apa ini
Skill untuk mengalibrasi AI coding agent ke sebuah project yang belum pernah dikerjakan sebelumnya — mendeteksi stack/tooling, install dependency, memverifikasi project benar-benar bisa jalan (dev server/build/test), lalu menulis atau memperbarui CLAUDE.md/AGENTS.md dengan apa yang ditemukan dan diverifikasi.

## Kapan dipakai
Di awal kerja pada repo baru/belum dikenal, atau saat user minta "onboard"/"bootstrap"/"setup project ini buat agent".

## Bukan untuk
Memasang skill dari katalog ini ke project lain (lihat `INSTALL.md` di root katalog ini) — skill ini untuk kalibrasi ke stack project *manapun*, dijalankan sekali per project, bukan setiap sesi.

## File terkait
- `SKILL.md` — instruksi lengkap skill ini.
