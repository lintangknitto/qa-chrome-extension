# security-and-hardening

## Apa ini
Skill untuk mengeraskan (harden) kode terhadap vulnerability.

## Kapan dipakai
Saat menangani input user, autentikasi, penyimpanan data, atau integrasi eksternal — atau saat membangun fitur apa pun yang menerima data tidak tepercaya, mengelola session user, atau berinteraksi dengan layanan pihak ketiga.

## File terkait
- `SKILL.md` — instruksi lengkap skill ini.
