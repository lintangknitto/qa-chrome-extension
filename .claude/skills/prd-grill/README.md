# prd-grill

## Apa ini
Skill untuk mengubah ide mentah jadi plan yang konkret dan bisa dieksekusi lewat tanya-jawab iteratif. Menanyakan satu pertanyaan setiap kali, menyesuaikan berdasarkan jawaban sebelumnya dan kondisi codebase yang ada, mengonfirmasi pemahaman, lalu selalu menulis pasangan PRD + ISSUES di `docs/prd/todo|done/` (lihat `references/output-conventions.md`) — format tetap, bukan hasil tebakan dari apa yang sudah ada di repo.

## Kapan dipakai
Trigger: `/prd-grill`, "grill me", "grill fitur ini", "ayo rencanakan ini", "bantu spec fitur ini", atau saat mulai fitur/project baru yang belum punya PRD/plan sama sekali.

## Bukan untuk
- Task satu baris yang trivial dan tidak butuh dokumen plan.
- Menurunkan ulang plan yang sudah ada — pakai flow refine/update untuk itu.

## File terkait
- `SKILL.md` — instruksi lengkap skill ini.
- `references/output-conventions.md` — konvensi format output PRD+ISSUES.
