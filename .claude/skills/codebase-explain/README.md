# codebase-explain

## Apa ini
Skill untuk menjelaskan sebuah repo, fitur, atau cara kerja sesuatu dengan bahasa yang sederhana dan non-teknis, berdasarkan kode aslinya (bukan asumsi), lalu ditulis sebagai file markdown yang bisa disimpan/dibagikan — bukan cuma jawaban di chat.

## Kapan dipakai
Saat orang non-developer (PM, stakeholder, karyawan baru, support) perlu memahami sebuah codebase atau flow tertentu, atau saat user minta "jelaskan repo/fitur ini dengan bahasa sederhana" dan menginginkan hasilnya berupa dokumen.

## Bukan untuk
- Dokumentasi API/developer-facing yang butuh presisi dan istilah teknis (justru kebalikan dari tujuan skill ini).
- CLAUDE.md/AGENTS.md — itu instruksi operasional untuk agent (lihat `project-bootstrap`), bukan dokumen untuk pemahaman manusia.

## File terkait
- `SKILL.md` — instruksi lengkap skill ini.
- `assets/explain-template.md` — template dokumen hasil penjelasan.
